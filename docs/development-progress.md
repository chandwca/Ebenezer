## Work completed in this audit

- New users see a standalone, two-step entry screen outside the dashboard shell. **Let’s get started** opens optional local profile setup; **Explore first** enters Today without details. Returning users bypass onboarding; `/welcome` provides a preview. Shared OnboardingLayout controls responsive visuals, language/theme actions and PWA setup status. No account is required.
- Names and arbitrary city names use the existing shared FormBuilder and IndexedDB preference repository. Settings still edits the same profile.
- Saved names personalize Today; invalid/missing preferences do not prevent the journal from being used.
- A shared keyboard-accessible ChoiceGroup supports passage cards and stone tones through FormBuilder. FeelingStones supports multiple feelings and optional free-text check-ins.
- Onboarding copy addresses studying away from home and is bundled in English/Spanish.
- Tests cover profile save/reopening, skipping/reopening, language switching without lost input, and existing reflection navigation/persistence.

- My Story now defaults to the shared SVG StoneTower. Real saved stones open an accessible StoneDetail dialog, with editing and confirmed deletion. Gold/navy/teal tone colours are common CSS tokens. Journal cards remain an alternate view; search and backup controls sit in a shared disclosure. Saved WEB snapshots and chapters supplement the three older bundled KJV excerpts. Browser checks exercise offline tower navigation and opening a saved memory.
- Walk the path now uses a shared winding stone path and conversational moments. Eleven feeling stones, optional own words, always-open reflection writing spaces, contextual actions, quiet draft status and a live final preview replace the boxed wizard. Multiple feelings/check-ins remain compatible with older single-feeling journals and backups. The combined Scripture moment automatically brings forward a WEB passage using the check-in and feelings with the existing 50-passage contextual embedding index; excerpts/chapters persist offline. A KJV care fallback remains. Retrieval quality review, LLM interpretation, audio and songs are still pending.
